# 🛰️ ABAP Atlas

ABAP Interview Atlas: SAP ABAP interview prep in one page (HANA, Basics, DDIC, ALV, OOPs, BADI, CDS, OData, IDoc, 70 Qs, Mock, Revise cards).

Everything is in **one file: `index.html`**. No install, no build.

## 🪟 Open on Windows

1. Click the green **Code** button → **Download ZIP**.
2. Right-click the ZIP → **Extract All**. (Do not open it from inside the ZIP.)
3. Double-click **`index.html`**. It opens in Edge or Chrome.

Tips:
- Keep using the same browser and the same file location: your progress (✅ modules, known cards, mock ratings) is saved in that browser only.
- Internet is needed only for the fonts. Offline, it still works with Windows fonts.
- 🔊 Read aloud uses Windows voices (e.g. Microsoft Heera / Ravi for Indian English, if installed in Settings → Time & language → Speech).

## 🌐 Open online (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
After a minute the site is at `https://krrivats.github.io/abap-atlas/`.
